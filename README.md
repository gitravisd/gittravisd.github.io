## Apps



## Adding a new app

1. Create a folder (e.g. `myapp/`) with an `index.html`
2. Commit and push to `main`
3. It's live at `https://<username>.github.io/myapp/` within a minute or two

## Notes

- Repo is public, so don't commit secrets or API keys
- Everything is client-side only (static hosting)
